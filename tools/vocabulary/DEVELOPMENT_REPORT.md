# 英语背词开发报告

已在静态个人网站中实现可用的词汇学习应用。工具入口为“英语背词”，独立路径 `tools/vocabulary/index.html`；资源及回到个人首页的导航适配 `/stray-articles/`。正式词库尚未提供，导入管道已完成验证，以后可直接上传 GLM TXT，无需改源码。

## 实现和使用

1. **主页和导航**：开始学习、开始检测、我的词库；真实每日新词、复习、到期、累计词数、连续天数及目标。词库为空时引导导入。
2. **个人词库**：创建、改名、切换、删除；多库共享同一词义进度。无其他引用的词在删除分类后归入默认库，学习数据保留。收藏、已学、未学、状态、到期、困难、考试分类及英文前缀搜索，25 条分页，按需加载详情和历史。
3. **导入**：结构化 TXT、Markdown、JSON、JSON Lines，UTF-8 BOM、常见换行；后台解析、规范化、独立词义及词性校验、错误行位置、保存前预览、合并/跳过、分批事务与报告。重复导入不重置学习。
4. **GLM 导出**：导入界面的“GLM 导出规范”可复制。推荐一行一个 JSON 对象的 UTF-8 `.txt`；`word` 和 `senses` 必需，每个 sense 必须有 `partOfSpeech, definitionEN, definitionZH`。IPA、来源/版本、双语例句、标签、频率和源 ID 可另外提供。三个覆盖多义、多词性和多考试的明确演示示例见 README 和界面，不冒充词典或考试内容。
5. **主动回忆**：先显示英文词、IPA 和词性，释义/例句隐藏；显示释义后才允许 Again/Hard/Good/Easy。展示每档真实调度间隔，收藏独立持久化，支持音频/美式 Web Speech fallback、约 500ms 转场、空格/1–4/B 键和减少动态效果。
6. **FSRS**：官方 MIT `ts-fsrs 5.4.2`、FSRS-6.0，随站保存，算法源码未修改。默认保持率 90%，可调 70–99%；短期 `1m,10m`，重新学习 `10m`，最大间隔 36500 天，不启用 fuzz。D/S/状态/时间/次数/lapses 和评级日志完整保存，R 由当前状态与时间计算。每个词义独立调度，不以记住一个含义代替掌握全部含义。
7. **每日计划与会话**：默认 20 个新单词，随机新词、到期优先、短期/重学义务和收藏同到期优先；日复习上限按独立 Review 词义计。暂停、刷新、跨日保留义务。重复评分用 revision、事件 ID、会话 index 和原子事务拒绝。
8. **词义频率**：真实 sense-level 的 count/sampleSize 标准化为每百万样本比例。仅在各词义语料覆盖和统计方法/单位相容时排序；合并考试对相容比例等权平均，资料缺失或不兼容则保留原始词义顺序。整词频率不作为词义频率，未编造语料数值。
9. **检测**：综合、收藏、困难、已学及指定范围。英译中题数 `round(N×0.3)`，中译英为余数，混合顺序；同词性有效干扰项，排除重复/已知同义释义，缺少选项时减少选项/题量并提示。提交锁定、反馈、分方向成绩、用户选择/正确答案、错题重做及历史均实际保存。
10. **双向高优先级**：可靠词义频率达到可调阈值（默认每百万 100），或用户明确 `highPriority:true`，才优先双向测试。两次出现间隔 1–3 个其他问题，计为两题且遵守总题数与 30/70。没有指标不强迫重复；单个目标词可缩减为一题，错题重做保留原方向。
11. **困难词和统计**：实际 Again 与检测错误关联 senseId/unitId；不将收藏等同于困难。提供词条/记忆单元/事件分别计量，7/30 天趋势、检测成绩、错词及错误率。掌握标准是所有词义均 Review、每义至少 3 次评分、S≥30 天且当前 R≥目标值。检测正确不会延长 FSRS 间隔。
12. **存储与隔离**：集中 IndexedDB `stray-vocabulary-<profile>`，schema v2；v1 自动增建 stateDue 组合索引，不重写历史。词库、词条、词义调度、事件、检测、会话和设置分表。索引查询、后台大导入及检测生成、分页、少量闪卡预读；每次评分只处理当前词义和同词摘要。
13. **备份恢复**：在“计划与数据”导出完整 JSON；上传备份后先校验版本、引用、调度数值、题目和答案，再明确确认替换当前档案。恢复是单个事务，失败不覆盖原数据；支持 v1 备份。不同档案/浏览器/设备的数据独立，需要手动备份跨设备转移，没有登录/云同步。

## 源码和技术栈

原生 HTML、CSS、模块 JavaScript，复用 `site.css` 和 `theme.js`。主要目录为 `tools/vocabulary/`，核心独立模块、页面模块及静态资源见 `README.md` 的文件表。`modules/contracts.d.ts`、JSDoc 和边界验证明确数据契约；没有将整个个人网站改为框架应用。FSRS 为唯一第三方运行时模块；ESLint、Playwright、Prettier 为开发工具。

## 测试与性能

`npm run lint`、`npm run build`、`npm test` 通过；33 项核心测试、61 项真实 Chromium/IndexedDB 检查，以及现有 Agent 工具 31 项回归检查均通过。浏览器完整流程包含上传 TXT、学习评分/收藏、检测和错题、继续学习、备份/恢复、刷新、正常磁盘档案浏览器重启和数据库版本迁移。没有将语法检查称为运行验证，也没有声称存在 TypeScript 编译步骤。

实际 Linux / 3 CPU / Chromium 151 条件下：10,000 条 TXT 后台解析 476.5ms，写入 6.00 秒，搜索 120ms，分类筛选 113.3ms，队列生成 159.4ms，完整恢复 6.73 秒。首页可用 779ms，学习页可用 1,316ms，20 张卡评分至下一步可用平均 577.7ms。另有 2,000 个多义词条/2,668 个记忆单元的导入及后台检测验证。具体数据、预算、硬件和内存测量限制在 `VALIDATION.md` 和 `tests/measurements.json`，包含首轮较慢存储结果，未泛化为所有设备保证。

## 预览与审查

在仓库根目录运行 `python -m http.server 8000 --bind 127.0.0.1`，打开 `http://127.0.0.1:8000/tools/vocabulary/index.html`。无需生产部署或任何运行时依赖安装。开发测试在子目录执行 `npm ci --ignore-scripts`，然后运行 README 中的命令。

变更仅为新增 `tools/vocabulary/` 和工具页入口。审查通过独立实现分支的草稿 PR，base 为 `feature/vocabulary`。没有修改/合并 main，没有修改 Pages 设置，没有部署生产。终端 gh 认证失效，GitHub 连接器已确认写权限，远程审查可通过该连接器完成；同时保留本地源文件与可转移的完整审查包。

## 外部数据与验证边界

真实词库、合法词典内容、音频和真实词义频率/考试例句资料以后由用户提供，不抓取或假冒。结构化导入不能自动证明每个译义的语言学准确性，明确同义词/语义分类元数据有助于消除歧义。无头测试不验证听感。已验证 Chromium 的桌面/平板/手机视口，未在 Windows、iPad Safari 或 Android 实机做端到端测试。本地档案是浏览器存储隔离，不是服务器账号授权。完整备份仍是防止浏览器清理数据的必要使用习惯。
