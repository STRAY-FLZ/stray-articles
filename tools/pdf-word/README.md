# PDF ⇄ Word 初版

地址：`tools/pdf-word/index.html`。用本地 HTTP 服务或 GitHub Pages 打开；ES 模块和 PDF worker 不支持直接通过 `file://` 双击使用。

```powershell
node tools/pdf-word/preview.cjs
```

打开 `http://127.0.0.1:4173/tools/pdf-word/`。也可用任意静态服务器服务整个网站目录。

## 功能

- PDF → DOCX：提取文字生成可编辑 Word；无文字页自动作为图片保留。另有页面图片模式，保留 PDF 视觉版式。
- 一键排版：PDF 转换完成后，点击文件右侧的“一键排版”，按原 PDF 的页面尺寸、分页、文字位置、字号和颜色生成另一份 DOCX。普通文字保留为可编辑文本框，图片、图形和表格边框作为页面背景保留。原转换文件不会被覆盖。
- 排版预览：排版完成后，可在“原 PDF / 转换结果 / 排版结果”之间对照查看；“下载排版”保存为 `原文件名-排版.docx`。排版预览与 DOCX 使用同一份页面位置数据，但属于排版示意，最终效果以 Word 打开为准。
- DOCX → PDF：Mammoth 提取基础内容，按 A4 重新排版，由 html2pdf 生成页面图像 PDF。
- 图片 → PDF：“上传图片”支持 JPG、PNG、WebP；一次最多 12 张，按选择顺序合成一份 PDF，每张一页、A4 等比例居中，不裁切。支持原图片与生成 PDF 预览及下载，也可将图片拖至 PDF 卡片。
- 文件选择、拖拽、多文件排队、原文与结果预览、下载、失败重试、删除与清空。
- 本地转换，不发送文档到任何服务器；所有依赖随页面提供，没有外部 CDN 请求。
- 沿用博客颜色和日夜模式；独立工具页，可从博客“工具”栏目进入。

## 当前限制

单个文件最大 150 MB（150 × 1024 × 1024 字节，包含等于上限的文件），队列 12 个任务，PDF 60 页；图片单次 12 张，每张最多 4,000 万像素，输出约 200 dpi 的 A4 页面，透明背景转白色；Word 内容高度上限 20,000 CSS 像素（约 20 页，实际取决于排版）。大文件仍在浏览器本地处理，可能耗时较长或受设备内存限制，建议逐个转换。不支持旧版 DOC、加密文件与 OCR。PDF 普通文字模式不复原复杂表格、多栏与插图；Word 转换不保留页眉页脚与精确分页，生成 PDF 的文字不可选中。PDF 和排版结果预览前 5 页，完整文件可下载。

一键排版尽量保留布局，并不保证完全复刻。扫描页、旋转/竖排文字及部分特殊字体、透明或裁切文字，按整页图像保留，并标明“不可编辑”；表格不是可直接增删行列的 Word 表格。设备缺少原字体时会替换为相近字体，因此换行或字形可能有差异。页面超过 Word 支持的 22 英寸边长等情况会提示排版失败，原转换文件仍可下载。

后续可以接入独立转换服务来提高复杂文档保真度；GitHub Pages 仅托管静态页面，目前使用浏览器转换，无需服务器。

## 依赖与许可证

依赖固定存放在 `vendor/`，对应许可证同目录保留：

| 库 | 版本 | 作用 | 许可证 |
| --- | --- | --- | --- |
| PDF.js | 6.3.289 | PDF 文字提取、预览及页面渲染 | Apache-2.0 |
| docx | 9.8.1 | DOCX 生成 | MIT |
| Mammoth | 1.13.0 | DOCX 内容读取 | BSD-2-Clause |
| html2pdf.js | 0.14.0 | HTML 转 PDF | MIT，捆绑依赖见附带许可证 |
| DOMPurify | 3.4.16 | 文档 HTML 清理 | MPL-2.0 或 Apache-2.0 |

这些是初版固定版本。发布前如升级依赖，应重新验证双向转换与预览。
