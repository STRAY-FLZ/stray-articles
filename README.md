# Stray 文字档案

个人文章网站的 GitHub Pages 发布版本。导航为“首页、灵感、随想、旅途、工具、关于”；阅读与写作排列在“灵感”，个人生活中的感想和经历收录在“随想”。

## 页面

- `index.html`：首页和栏目入口
- `inspiration/`：阅读、观察与写作的文章列表
- `thoughts/`：个人生活中的感想和经历，目前收录《【IAG2.0】你的收官，我的开始》
- `topics/people/`、`topics/visual/`、`topics/world/`：旧栏目链接，自动跳转到“灵感”
- `travel/`：旅途栏目，保留原有网址
- `tools/`：笔记和小工具栏目，含文档格式互转工具
- `tools/pdf-word/`：PDF 与 Word 互转、图片制作 PDF、一键排版和预览。单文件上限 150 MB，文件在浏览器本地处理。功能、限制和本地启动方式见 [使用说明](tools/pdf-word/README.md)。
- `about/`：关于网站
- `articles/`：五篇文章的正文，其中四篇灵感、一篇随想

## 文章的统一字体与字号

在 `site.css` 最后的 `:is(.thoughts-reading, .article-layout)` 样式中统一设置字体；所有五篇文章及未来新增文章的标题为 `28pt`（28 磅），正文为 `14pt`（14 磅），电脑和手机使用同一字号。首选“华文中宋 / STZhongsong”，访客未安装该字体时依次使用备用宋体。网站不附带或分发商业字体文件，文章正文不作改写。

新增文章的正文路径是 `articles/iag2-your-finale-my-beginning/index.html`，日期沿用原文的 2026 年 10 月 2 日。

## 日间与夜间模式

“关于”后面的图标开关可以随时切换模式。首次访问跟随设备的深浅色设置；手动选择后，刷新、换页和下次访问会记住所选模式。同一浏览器里打开的其他页面也会同步切换。隐私设置禁用本地存储时，当页仍可正常切换，但无法记住选择。

夜间颜色在 `site.css` 的 `:root[data-theme="dark"]` 中统一设置，正文的字体、字号和排版不变。夜间图案使用原始的 `assets/icons/night-symbol.png`，通过 CSS 亮度遮罩去掉黑色底色，原图不作修改。

## 加入自己的美术

把图片放进 `assets/art/`，然后在 `art.css` 设置对应图片路径和配色。具体尺寸、变量和示例见 [ART_GUIDE.md](ART_GUIDE.md)。网站自带默认抽象图形，暂时没有个人作品也能正常展示。

## 发布与更新

在仓库的 **Settings → Pages** 中，选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`。以后更新网页、文章或美术文件，提交到 `main` 后即可重新发布。

本站内容和上传的图片会公开展示。发布前请核对文章署名、正文和图片使用权。
